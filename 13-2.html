SVG 图标（Scalable Vector Graphics）实现原理

技术本质：Lucide 是一套纯粹基于 SVG（可缩放矢量图形）的轻量开源图标库。在页面中声明带有 data-lucide="图标名" 的占位标签，引入 lucide.min.js 并调用 lucide.createIcons()，脚本会自动将占位标签替换为标准的 <svg><path d="..." /></svg> DOM 节点。

SVG 独特优势：支持细粒度控制线条粗细（stroke-width）、端点与折角样式（stroke-linecap、stroke-linejoin）、多色及镂空填充（fill），并能实现令人惊叹的 SVG 描边动画（stroke-dasharray），彻底摆脱字体渲染反锯齿模糊问题！

技术选型对比：Font Awesome（字体图标） VS Lucide（SVG 图标）
对比维度 Font Awesome (13-1.html · 字体图标方式) Lucide (13-2.html · SVG 图标方式)
实现底层 @font-face 载入矢量字体文件，通过 ::before 输出 Unicode 字符。 直接在 DOM 中生成 <svg><path> 矢量图形节点。
线宽调节 ❌ 不支持（字体的笔画粗细由字体文件固定，无法动态变细或变粗）。 ✅ 完美支持（可直接设置 stroke-width="1.5" 任意调节粗细）。
双色与填充 ❌ 字体默认只能是单色（受限于 text color），无法实现复杂局部填充。 ✅ 支持分别控制 stroke（描边）与 fill（填充），支持渐变色。
渲染清晰度 受浏览器文字反锯齿（Antialiasing）与子像素渲染影响，特定字号可能微糊。 纯矢量数学几何，高分屏与任何缩放比下 100% 绝对锐利清晰。
高级动效 仅支持常规 CSS 旋转、缩放、透明度动画。 支持独有的 SVG 路径描边绘制动画（stroke-dashoffset）与图形变形。
