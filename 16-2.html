                        系统化梳理面试高频考点与开发核心规则
                    

                

            


            

                

                    
                        

                            对比维度 / 概念
                            核心语法 / API
                            行为特性与工作原理
                            典型应用场景 / 注意事项
                        

                    
                    
                        

                            属性访问方式
                            obj.prop vs obj['prop']
                            点语法简洁直接；中括号语法支持动态变量键名、包含连字符或空格等特殊字符的键名。
                            当属性名保存在变量中时，必须使用中括号语法，例如 obj[dynamicKey]。
                        

                        

                            属性遍历机制
                            Object.keys() vs for...in
                            Object.keys() 仅返回对象自身可枚举属性；for...in 会沿着原型链向上查找原型上的可枚举属性。
                            遍历普通对象属性强烈推荐使用 Object.keys(obj).forEach() 或 Object.entries()。
                        

                        

                            属性存在性判断
                            Object.hasOwn() vs in 操作符
                            Object.hasOwn(obj, k) 仅检查自身属性；k in obj 会检索自身及原型链继承属性。
                            ES2022 推荐使用 Object.hasOwn() 替代过往的 obj.hasOwnProperty()。
                        

                        

                            对象浅拷贝与合并
                            Object.assign() 与 { ...obj }
                            将源对象的所有自身可枚举属性复制到目标对象。注意：只拷贝第一层，嵌套对象仅复制引用地址。
                            若修改复制品中的嵌套对象，原对象的对应嵌套属性也会被改变。
                        

                        

                            对象深拷贝
                            structuredClone(obj)
                            现代浏览器原生深拷贝 API，完全递归复制所有层级对象与数组，彻底隔离原对象引用。
                            传统 JSON.parse(JSON.stringify(obj)) 会丢失方法、undefined、Symbol 等。
                        

                        

                            对象锁定保护
                            freeze() vs seal() vs preventExtensions()
                            
                                preventExtensions：不可加，可删可改。

                                seal (密封)：不可加不可删，可改已有值。

                                freeze (冻结)：不可加、不可删、不可改（全锁定）。
                            		
                            注意它们都是浅层保护；如需深冻结需编写递归冻结函数。严格模式下违反保护会抛出 TypeError。
