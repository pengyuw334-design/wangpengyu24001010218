1 数值型 (Number)
typeof: "number"
let crx_num = 2026;
let crx_price = 99.85;
let crx_nan = NaN; // 非数字
类型分类： 基本数据类型（栈内存存储）
常见取值： 整数、浮点数、NaN、Infinity
📌 注意：NaN（Not a Number）也是 number 类型，且 NaN !== NaN。

2 字符串型 (String)
typeof: "string"
let crx_author = "王鹏宇";
let crx_msg = `欢迎学习JS`;
类型分类： 基本数据类型（栈内存存储）
表示语法： 单引号 ''、双引号 ""、反引号 ``
📌 注意：字符串是不可变的，反引号支持模板插值 `${expression}`。
等待测试...
3 布尔型 (Boolean)
typeof: "boolean"
let crx_isPassed = true;
let crx_isFinished = false;
类型分类： 基本数据类型（栈内存存储）
可能取值： 仅有 true 与 false 两个逻辑字面量
📌 注意：常用于条件判断语句（if / while）及逻辑控制。
等待测试...
4 未定义型 (Undefined)
typeof: "undefined"
let crx_unassigned;
// 变量已声明但未赋值时的初始状态
类型分类： 基本数据类型（栈内存存储）
唯一取值： undefined
📌 注意：未声明直接访问会报错，但对未声明变量 typeof 也返回 undefined。
等待测试...
5 空值型 (Null)
typeof: "object" ⚠️
let crx_emptyObj = null;
// 表示一个空对象指针引用
类型分类： 基本数据类型（表示空指针）
唯一取值： null
📌 经典考点：typeof null 结果为 "object"，这是早期的设计历史遗留特性。
等待测试...
6 对象型 (Object)
typeof: "object"
let crx_student = {
  crx_name: "王鹏宇",
  crx_skills: ["HTML", "JS"]
};
类型分类： 复杂引用数据类型（堆内存存储）
包括范畴： 普通对象、数组 Array、函数 Function
📌 注意：变量存储的是堆内存的引用地址；函数也是对象（typeof 返回 function）。

📊 JavaScript 数据类型特征全景对比表

序号 数据类型名称 存储类别 示例声明代码 typeof 返回值 内存存储机制 核心说明与注意事项
1 Number (数值型) 基本类型 let crx_a = 100; "number" 栈内存 (Stack) 包含整数、浮点数以及特殊数值 NaN、Infinity
2 String (字符串型) 基本类型 let crx_b = "王鹏宇"; "string" 栈内存 (Stack) 文本数据，不可变序列，可通过索引或 length 访问
3 Boolean (布尔型) 基本类型 let crx_c = true; "boolean" 栈内存 (Stack) 真假标志位，只有 true 和 false 两种值
4 Undefined (未定义) 基本类型 let crx_d; "undefined" 栈内存 (Stack) 声明但尚未赋值的变量的系统默认初始值
5 Null (空值) 基本类型 let crx_e = null; "object" 栈内存 (Stack) 表示空对象指针引用；null == undefined 为真，但 === 为假
6 Object (对象引用) 引用类型 let crx_f = {x: 1}; "object" / "function" 堆内存 (Heap) 键值对集合，包含普通对象、数组以及函数（Function）
