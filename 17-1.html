💡 什么是 JSON？
JavaScript Object Notation，轻量级文本数据交换格式，独立于语言，具备极高的可读性。
⚙️ JSON.parse()
将符合标准 JSON 语法的字符串转换为 JavaScript 对象或数组，若语法有误会抛出异常。
📦 JSON.stringify()
将 JavaScript 对象或数组序列化为 JSON 字符串，支持传递参数进行缩进排版美化。
