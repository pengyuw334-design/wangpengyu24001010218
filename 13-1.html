字体图标（Font Icons）实现原理

技术本质：Font Awesome 字体图标是将矢量图标像英文字母一样打包进字体文件（.woff2 / .ttf）中。通过 CSS 规则 @font-face 载入自定义字体，再利用伪元素 i::before { content: "\f015"; } 将特定 Unicode 编码字符呈现在网页中。

主要优势：可以完全像普通文字一样，通过 CSS 样式 font-size、color、text-shadow 任意缩放控制，矢量高清且体积紧凑。

字体图标的丰富特性（尺寸、色彩、旋转、叠层、动画）

尺寸等级控制

内置类 fa-xs 到 fa-3x，亦可直接写 font-size: 32px。

颜色与文字阴影

继承 CSS 字体样式，使用 color 与 text-shadow 产生文字光晕。

旋转与镜像翻转

使用 fa-rotate-90/180/270 与 fa-flip-* 实现翻转。

动态旋转加载

使用 fa-spin 或 fa-pulse（8步节拍旋转）赋予动效。

叠层组合图标 (fa-stack)

通过 fa-stack 将两枚图标叠合，创造复合新图标。
