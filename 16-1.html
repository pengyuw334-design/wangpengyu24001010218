容易踩的 5 个坑

            
名字很像，行为差很远。

        

        

            

                🪓
                
slice 与 splice，一字之差

                
slice 是“切一段出来”，返回新数组；splice 是“在原数组上剪接”，会改变原数组。

                cart.slice(0, 2)   // 新数组，原数组不变
cart.splice(0, 2)  // 原数组被剪掉 2 件
            

            

                ⚠️
                
sort() 默认按字符串排

                
不传比较函数时，元素会先转成字符串再比较，所以 10 会排在 2 前面。

                [10, 2, 1].sort()              // [1, 10, 2]
[10, 2, 1].sort((a, b) => a - b)  // [1, 2, 10]
            

            

                🔁
                
forEach 不是 map

                
forEach 只负责遍历，返回 undefined；map 会把每个元素的加工结果装进新数组。

                cart.forEach(item => console.log(item)) // undefined
cart.map(item => CATALOG[item].price)   // 新数组
            

            

                🎯
                
find 与 filter

                
find 只返回第一个匹配的元素，找不到是 undefined；filter 返回所有匹配元素组成的新数组，找不到是空数组。

                cart.find(item => price < 10)   // 一个元素
cart.filter(item => price < 10) // 一个数组
            

            

                🧩
                
空数组的 some / every

                
空数组里找不到任何反例：some 返回 false，every 反而返回 true。

                [].some(item => item > 0)  // false
[].every(item => item > 0) // true
